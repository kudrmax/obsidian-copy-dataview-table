# Copy Dataview Table

Copies the result of a Dataview query to the clipboard as Markdown.

- **Copy button.** In Live Preview every ` ```dataview ` block gets a copy button next to «Edit this block».
- **Command «Copy first Dataview table in note».** Copies the first ` ```dataview ` block of the open note.

Links stay links (`[[Note|Name]]`). `dataviewjs` blocks are not copied. Needs the Dataview plugin.
